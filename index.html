LOCAL NETWORK HELPER

Phone Preview Tool

Open a website running on your Windows PC from your phone on the same Wi-Fi.

1 Detect your PC's IP and running website

Press one button: it finds this PC's Wi-Fi address, checks common website ports, verifies the site answers, and builds the QR code. It only tests this PC, so it cannot see other devices.

Tip: if you started this page with PhonePreview.exe or start.bat, the PC IPv4 is already detected — just press Detect.

Fills the IP and port below, then verifies the website answers.

Manual fallback

If detection cannot find the address (some browsers hide it), use the Windows command below.

ipconfig
  1. Open Command Prompt or PowerShell on the PC.
  2. Run ipconfig.
  3. Under the active Wi-Fi adapter, find IPv4 Address, e.g. 192.168.1.5.
  4. Enter that address below. Do not enter 127.0.0.1 or localhost.

2 Set the website port

Detection fills this automatically. Change it only if the website uses a different port (for the example site, use 8080).

3 Start the website so your phone can reach it

Easiest (no typing): drag your website folder onto PhonePreview.exe (or start.bat if you have Python). The server starts on your PC's IPv4 address, the browser opens by itself, and Detect works in one click.

Manual option: in the terminal, stop the old server with Ctrl + C, then restart it from the website's folder:

python -m http.server 8080 --bind 0.0.0.0

Run this command in the folder containing the website's index.html. Keep the terminal open while testing. With this manual server, if Detect shows a .local warning, prefer PhonePreview.exe / start.bat so the IPv4 is detected automatically.

Important: if the website already uses port 8080, do not start another server on the same port. Stop the existing server first, then restart it with --bind 0.0.0.0.

4 If Windows Firewall blocks it

Try the URL first. The first time the server runs, Windows may ask for network access — click Allow access and keep Private networks checked. Only if the phone still cannot connect, open PowerShell as Administrator and run this command:

New-NetFirewallRule -DisplayName "Phone Preview TCP 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Private

This adds an inbound rule for port 8080 on Private networks. To remove it later, run:

Remove-NetFirewallRule -DisplayName "Phone Preview TCP 8080"

Only allow access on a trusted private network. Do not create a public tunnel unless you understand that it can expose your website to the internet.

5 Quick troubleshooting

If one-click detection cannot find your PC address, some browsers hide it on purpose — use PhonePreview.exe or start.bat, or run ipconfig and type the IPv4 manually. The QR library is bundled in this folder, so QR codes work without internet.
