# MT-pc-localshot-to-phone
Pc က project တွေကို local မှာ testing လုပ်တဲ့အခါ ဖုန်းကနေပါ လှမ်းပီး testing လုပ်လို့အောင် 1 click တည်းနဲ့ localhost sharing Qr code ထုတ်ပေးနိုင်ပါတယ်၊

## 📥 Download (Windows)

**[⬇️ PhonePreview.exe — latest](https://github.com/Ehso9966/MT-pc-localshot-to-phone/releases/latest/download/PhonePreview.exe)**

> No Python needed. Desktop app window (not a browser tab). Pick your website folder → scan the QR with your phone.

All versions: **[Releases page](https://github.com/Ehso9966/MT-pc-localshot-to-phone/releases)**

## Quick start
1. Download `PhonePreview.exe` above, plus [`install.bat`](install.bat) and [`install.ps1`](install.ps1) into the same folder.
2. Double-click **`install.bat`** — an install window opens with checkboxes:
   - `[x]` **Create a desktop shortcut**
   - `[x]` **Add to Start Menu**
   Tick what you want, then click **Install**.
3. Double-click the **Phone Preview** icon — the app window opens.
4. Click **Open website folder…** (or drag the folder onto the window).
5. Click **Detect server (one click)**, then scan the QR with your phone (same Wi-Fi).
